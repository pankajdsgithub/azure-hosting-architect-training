# HLD and LLD Template Pack

This folder contains Microsoft-style architecture template packs for client-facing design documents.

## Included templates

- `hld-template.md` — High-Level Design template
- `lld-template.md` — Low-Level Design template
- `adr-template.md` — Architecture Decision Record template

## Usage

Use these templates to document:

- business and technical scope
- architecture decisions
- environment boundaries
- security and networking design
- data and integration model
- deployment and operational controls
- risks, assumptions, and open issues

## Suggested order

1. Requirements and business context
2. HLD document
3. LLD document
4. ADRs for major architecture choices
5. Review and sign-off
